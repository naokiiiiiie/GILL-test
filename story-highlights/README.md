# GiLL フレーバー紹介ストーリー（ハイライト用）

Instagram のストーリー／ハイライトで、GiLL のジェラートフレーバーを紹介するための
背景テンプレート画像です。**ジェラートの写真はあとから差し込む**前提で、
それ以外のデザイン（見出し・説明文・猫耳の写真枠・装飾）を作り込んでいます。

- サイズ: **1080 × 1920 px**（ストーリー規格 9:16）
- テイスト: GiLL のサイトに合わせた和モダン／猫テーマ（温かいオフホワイト＋木目、明朝体 Shippori Mincho）
- 各スライドに **猫耳つきの丸い写真枠**（「ここにジェラート写真」の部分）があり、そこにジェラート写真を重ねるだけで完成します

## ジェラート写真の差し込み方（例）

1. Instagram のストーリー編集、または Canva などで、この背景画像を配置
2. 撮影したジェラート写真を、丸い写真枠（猫耳の下）に合わせて円形に切り抜いて重ねる
3. 「ここにジェラート写真 / Gelato photo」のガイド文字が隠れる位置に置けば完成

> 写真枠は各スライドのフレーバーに合わせた淡いアクセントカラーになっています。

## デザインの再編集・再書き出し

デザインは `stories.html` 1枚で管理しています（フレーバー名・説明文・色は
ファイル冒頭の `flavors` 配列を編集するだけで変更できます）。

再書き出し（要 Node.js + Playwright + Chromium）:

```bash
# 使用フォント: Shippori Mincho / Zen Kaku Gothic New（Google Fonts）
node render.mjs ./images 1   # 第2引数の倍率を 2 にすると 2160x3840 の高解像度で書き出し
```
