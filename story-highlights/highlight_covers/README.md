# GiLL ハイライトカバー（各カラー版）

Instagram プロフィールの**ストーリーハイライト用カバーアイコン**です。

## 修正内容
以前のカバーは、アクセント線の色は違うものの**背景がすべて同じクリーム色 (#f5ede3)** で、
丸いカバー表示ではすべて同じ色に見えていました。
今回、**各ハイライトのカラーに沿って背景色を変え**、プロフィール上でひと目で見分けられるように
作り直しています。デザイン（同心円・アイコン・和文＋欧文ラベル・GiLL）は踏襲し、
フォントは GiLL の明朝体（Shippori Mincho）に統一しました。

## 一覧（全6枚 / 1080×1080px）
| ファイル | ハイライト | 背景カラー | アイコン |
|----------|-----------|-----------|---------|
| `hl-menu`     | メニュー / MENU            | 淡ピンク  | ジェラート |
| `hl-seasonal` | 今月の限定 / SEASONAL      | 淡ゴールド | リーフ |
| `hl-catgoods` | 猫雑貨 / CAT GOODS         | 淡ラベンダー | 猫 |
| `hl-access`   | アクセス / ACCESS          | 淡セージ  | ピン |
| `hl-reviews`  | 口コミ / REVIEWS           | 淡ブルー  | 吹き出し |
| `hl-info`     | お知らせ / INFORMATION     | 淡ベージュ | インフォ |

- `png/` … そのままアップロードして使える PNG
- `svg/` … 編集用（テキスト・色をコードで調整可）
- `_preview_all.png` … 6枚を丸表示で並べた確認用シート

> ハイライトカバーは Instagram アプリ上で円形にトリミングされます。中央にデザインを寄せています。

## 再編集・再書き出し
`build-covers.mjs` の `covers` 配列で、ラベル・背景色（`bg`）・アクセント色（`accent`）・
アイコン種別を変更できます。

```bash
node build-covers.mjs ./covers_out   # svg/ と png/ を書き出し
```
